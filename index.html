Multi Chat Twitch

0 canais
Você abriu o arquivo direto do disco (file://). O embed da Twitch só funciona via http(s) — sirva a pasta com um servidor local (ex.: python -m http.server 8000) e abra http://localhost:8000.
Para conversar: clique em Entrar em qualquer um dos chats e faça login na Twitch uma única vez — vale para todos os chats desta página e fica lembrado neste site.

Nenhum canal na URL

Passe os canais da Twitch na query string, separados por vírgula:

index.html?canal=gaules,alanzoka,cohlay

Ou use o campo acima para adicionar canais.
